# Preview optimization decisions

These Chromium studies isolate different workloads. Compare the two variants within each study: combining the smaller download and preloading would overlap some of the same transfer, so their savings should not be added. The results describe benchmark prototypes.

- **Prioritize a smaller renderer download.** Keeping three common fonts in the module and loading eleven fonts and predefined character maps only when needed cut the first invoice's engine transfer from 1.43 MB to 0.95 MB. First preview fell from 1.30 s to 0.91 s on the paced link. Raster output matched on the tested invoices, scan, rotated page, named-character-map fixture and all-font sheet. [Size, timing and fidelity measurements](bundle-study.md)

- **Load on review intent.** On one shared 10 Mbit/s link, starting WASM compilation as the packet list became ready saved 507 ms after a 500 ms choice and about 1.19 s after a 1.5 s choice. It did not help immediate clicks. Completed preloads cost 1.43 MB on visits with no open. Prefer a likely-to-review signal over unconditional preload. [Preload measurements](preload-study.md)
- **Treat large scans as an I/O problem.** Reading a 250-page, 59.28 MiB independent-scan file before painting took 11.72 s for Leafview at 50 Mbit/s; a same-length PDF sharing one scan took 0.54 s. With PDF.js, range requests cut PDF bytes by 73%, but on this file layout the client still made 253 requests. Test a layout optimized for first-page access or a separate first-page preview before investing in a range-aware Leafview parser. [Scan measurements](scans-study.md)
- **Trial worker canvas presentation at high resolution.** At 1,600 pixels wide the worker bitmap path cut median render completion from 12.4 to 8.2 ms and median peak browser private memory from 251.8 to 187.5 MiB. At 900 pixels it also saved memory, but p95 time to a verified frame rose from 40.3 to 57.6 ms. Keep the current 900-pixel path pending a full viewer trial. See [render timing, memory and visual equivalence](canvas-study.md).
